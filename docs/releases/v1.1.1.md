# Any2Any v1.1.1

This release makes the documentation easier to read. **The app hasn't changed:** Any2Any.exe is identical to the executable in v1.1.0. If you already have it, you don't need to download it again.

## What's changed

- A shorter README, with downloads and getting-started instructions up front.
- Clear examples of normal conversions and creative interpretations.
- Detailed settings and developer notes moved into a separate technical guide.

## Download

Download **Any2Any.exe** below, copy it to any folder, and open it. It runs on Windows x64 without Python or an installer. FFmpeg is included; LibreOffice, OCR, and speech recognition remain optional.

The attached **SHA256SUMS.txt** confirms that the executable matches v1.1.0.
